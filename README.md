# gentifi.com

The Gentifi concept website, built with [Astro](https://astro.build).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

Every push to `main` builds and deploys to GitHub Pages at https://gentifi.com.

## Pages

| Path | Page |
| --- | --- |
| `/` | Home |
| `/businesses` | For businesses |
| `/how-it-works` | How it works, in detail |
| `/toolkit` | Open-source toolkit |
| `/standards` | Open standards, and the Business Collections draft 0.2 with explorer and validator |
| `/b/demo-business` | Scan-to-add demo (fictional business), with its generated agent files |

## Generated files

`public/b/demo-business/` holds real agent files for the fictional demo business (discovery manifest, MCP server card, Agent Skill, schema.org data and sticker), generated by the toolkit from its `examples/demo-farm-shop.csv`. To regenerate them, run `gentifi build` on `public/b/demo-business/gentifi.json` and copy everything except `index.html` back. `public/standards/` serves the Business Collections JSON Schemas; copy them from collections-spec when the draft changes. `public/og/gentifi.png` is the share image.

Related repos: [gentifi-toolkit](https://github.com/SelfBankt/gentifi-toolkit) · [collections-spec](https://github.com/SelfBankt/collections-spec)
